# PHP Forge 1.0 — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Jalon 1.0 (§8) : performances (§3) — réouverture avec cache sous 3 s, mémoire du serveur sous 1,5 Go, références d'une fonction très utilisée sous 2 s —, traduction française complète, documentation et empaquetage 1.0.0 (la publication sur le Marketplace et Open VSX est faite par l'utilisateur).

**Architecture:** Le cache de l'index devient un fichier de lignes JSON compressé (une ligne d'en-tête avec la version, une ligne par fichier) lu et écrit en flux : plus de document de 260 Mo ni de tampon décompressé entier en mémoire ; il n'est réécrit que si une entrée a changé, et il est lu pendant le listage du dossier. Les références passent par un filtre textuel avant l'analyse d'un fichier candidat : un fichier qui ne cite le nom qu'en méthode, propriété, variable, commentaire ou HTML n'est plus analysé.

**Tech Stack:** identique à 0.9.

**Spec:** `docs/superpowers/specs/2026-10-04-php-forge-design.md` — jalon 1.0 (§8), §3 (performances visées).

## Global Constraints

- Mêmes règles qu'aux jalons précédents (commentaires en français, textes d'interface en anglais via `l10n.t` traduits, commits sans attribution, jamais de push ni de publication).
- Version `1.0.0`, plus de `preview`.
- Mesures avant ce plan (serveur réel sur CRM-FR, 18 860 fichiers) : réouverture 6,4 s (cible < 3 s), mémoire 1,43–1,75 Go selon le moment du ramasse-miettes (cible < 1,5 Go), références au plus 3,0 s (cible fixée à 2 s dans la note de reprise). Le brouillon validé donne : réouverture 3,1 s du lancement du processus (2,9 s d'indexation annoncée par le serveur), mémoire 1,22–1,33 Go, références au plus 1,94 s pour le même nombre de résultats (12 227).
- `CACHE_VERSION` 10 : l'ancien cache (un seul document JSON) est reconstruit une fois.

## Review Focus

- **Cache tronqué ou corrompu au milieu du flux** (machine arrêtée pendant l'écriture) : reconstruit, jamais d'exception — tests de la tâche 1 (gzip invalide ; écriture dans un fichier temporaire renommé à la fin).
- **Fichiers ignorés (trop gros, binaires)** : ne forcent pas la réécriture du cache à chaque ouverture — test de la tâche 1.
- **Renommer une fonction** : le filtre textuel ne doit jamais faire perdre une référence (appel qualifié `\Lib\f()`, `use function`, callable `'f'`, `f(...)`) — tests de la tâche 2 et nombre de références identique sur CRM-FR (tâche 4).
- **Nom de fonction qui est un mot courant** (`type`, `all`) : fichiers qui ne le citent qu'en texte non analysés — test de la tâche 2.
- **Mémoire au démarrage d'un gros projet sans cache** : pas d'arrêt du serveur faute de mémoire — mesure de la tâche 4.

// Cache disque de l'index : résumé, taille et date de chaque fichier, en lignes JSON compressées (une ligne d'en-tête
// avec la version, puis une ligne par fichier), lues et écrites en flux : jamais de document de centaines de Mo en
// mémoire (pic de mémoire du serveur à l'ouverture d'un gros projet).
import { createHash } from 'node:crypto';
import { createReadStream, createWriteStream } from 'node:fs';
import { mkdir, rename, rm } from 'node:fs/promises';
import { once } from 'node:events';
import path from 'node:path';
import { createInterface } from 'node:readline';
import { pipeline } from 'node:stream/promises';
import { createGunzip, createGzip } from 'node:zlib';
import type { FileSymbols } from '../../shared/types.ts';

/** À incrémenter à chaque changement du format des résumés (FileSymbols), de l'extraction ou du fichier. */
export const CACHE_VERSION = 10;

export interface CacheEntry {
  size: number;
  mtimeMs: number;
  file: FileSymbols;
}

export function cacheFileFor(storageDir: string, folder: string): string {
  return path.join(storageDir, `index-${createHash('sha1').update(folder).digest('hex').slice(0, 16)}.json.gz`);
}

/** Cache d'un dossier ; absent, illisible ou d'une autre version : supprimé et vide. */
export async function loadCache(file: string): Promise<Map<string, CacheEntry>> {
  const entries = new Map<string, CacheEntry>();
  const raw = createReadStream(file);
  const input = raw.pipe(createGunzip());
  try {
    // Erreur de lecture (fichier absent) ou de décompression : `pipe` ne transmet pas les erreurs, écoutées ici
    const failed = new Promise<never>((_, reject) => {
      raw.on('error', reject);
      input.on('error', reject);
    });
    failed.catch(() => undefined);
    let header = true;
    const lines = createInterface({ input, crlfDelay: Infinity });
    const read = (async () => {
      for await (const line of lines) {
        if (header) {
          // Ancien format (un seul document) ou autre version : à reconstruire
          if (!line.startsWith('{"version":') || (JSON.parse(line) as { version?: number }).version !== CACHE_VERSION) throw new Error('version');
          header = false;
        } else if (line) {
          const [key, entry] = JSON.parse(line) as [string, CacheEntry];
          entries.set(key, entry);
        }
      }
    })();
    await Promise.race([read, failed]);
    if (header) throw new Error('empty');
    return entries;
  } catch {
    raw.destroy();
    input.destroy();
    await rm(file, { force: true });
    return new Map();
  }
}

export async function saveCache(file: string, entries: Map<string, CacheEntry>): Promise<void> {
  await mkdir(path.dirname(file), { recursive: true });
  const tmp = `${file}.${process.pid}.tmp`;
  const gzip = createGzip();
  const done = pipeline(gzip, createWriteStream(tmp));
  const write = async (line: string) => {
    if (!gzip.write(`${line}\n`)) await once(gzip, 'drain');
  };
  await write(JSON.stringify({ version: CACHE_VERSION }));
  for (const entry of entries) await write(JSON.stringify(entry));
  gzip.end();
  await done;
  await rename(tmp, file);
}
