# Changelog

## 1.1.0
- Stage / Unstage Changes removed from the view (inline buttons and right-click menu): use the Source Control view.
- Revert uploads: a button in the view title puts back on the server the files as they were before your uploads since the last commit (changed files restored, new files deleted, deleted files restored). Requires FTP SFTP Deploy 1.2.0.

## 1.0.1
- Repository, issues and homepage links on the Marketplace page.

## 1.0.0
- First release: Changed Files view (staged, modified, untracked, conflicts, since a base branch), flat list mode, Explorer-like context menu, multi-selection, optional one-click deploy with FTP SFTP Deploy. English and French.
